📖 What is VibeKeys?

VibeKeys turns your mouse actions into keyboard commands. Users who spend time in terminal windows often find it slow to move back and forth between the keyboard and mouse. This tool fixes that gap. It allows you to trigger mouse clicks, movements, and scrolls using configured key strokes. You keep your hands on the home row, which makes your work faster and more fluid.

🚀 Getting Started

Follow these steps to set up the software on your Windows computer.

  1. Visit the releases page to download the software.
  2. Locate the latest file ending in .exe.
  3. Click the file to save it to your computer.
  4. Double-click the downloaded file to start the installer.
  5. Follow the prompts on your screen to finish the setup.

⚙️ System Requirements

VibeKeys works on modern versions of Windows. You need at least 200MB of free disk space. The app uses very little memory, so it will not slow down your daily work. We built this to run quietly in the background while you use your terminal or other applications.

⌨️ How to Use VibeKeys

Once you open the app, it sits in your system tray near the clock. Right-click the icon to view your settings. You can map any mouse movement to a specific key combination. For example, you can assign "Control + Shift + M" to move your mouse to the center of the screen. You can also assign the left click, right click, or scroll wheel to various keys.

🛡️ Security and Privacy

This software runs locally on your machine. It does not send your data to any servers. The mouse mapping features work only when the application is active. You maintain full control over the inputs. You can close the application at any time by right-clicking the tray icon and selecting Exit.

🛠️ Troubleshooting

If the software does not respond, try restarting the application. Ensure that you have the latest drivers for your mouse. If you face issues, check the releases page again to ensure you have the most recent version. Most issues resolve after a simple reinstall or a system restart.
